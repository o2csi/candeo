# What's new, one change at a time

A change users will see adds a file here, in its own pull request: one line in
English, one in French, as the Store's *What's new* shows them. The French uses
the interface's words.

```text
en: Status row, a new effect: one key of the top row per signal received.
fr: Status row, un nouvel effet : une touche de la rangée du haut par signal reçu.
```

A release sends the lines of the files added since the previous release, in the
order of their names (#220, `docs/releasing.md`). Released files stay.
