Windows

On 64-bit Windows, Candeo is the package the Microsoft Store signs, however you install it: from the Store, with winget, or downloaded from a release as Candeo_<version>_x64.msix and opened with a double click. Signed by Microsoft, it shows no warning.

Its first launch takes the free licence the Store gives every app: the computer needs the Microsoft Store, and on a Windows without it Candeo does not start.

With winget, the Store's catalogue has it now; once its own manifest is accepted, the identifier is O2CSI.Candeo:

winget install --id 9MXFM8QT1X7P -s msstore
winget install O2CSI.Candeo

Installed before with candeo_<version>_x64-setup.exe or the .msi? They are no longer published. Uninstall that version in Settings › Apps, then install the package: your settings and your effects stay where they are.

Linux

Candeo runs on Linux, and support for real devices there is still being finished (#230). Both packages install the udev rule that lets your account talk to the device: plug it in again afterwards.

sudo apt install ./candeo_<version>_amd64.deb
sudo dnf install ./candeo-<version>-1.x86_64.rpm

The system packages Candeo needs, and the rule itself, are described in docs/linux.md.

Check a download

Every release carries a SHA256SUMS file listing the fingerprint of each download. In the folder holding both, on Linux:

sha256sum -c SHA256SUMS --ignore-missing

On Windows, compare with the line for your file in SHA256SUMS:

Get-FileHash .\Candeo_*_x64.msix -Algorithm SHA256

Updates

The Store updates Candeo by itself, and winget upgrade does with winget. On Linux, Candeo can tell you when a newer version is published — the one request it makes, which you can turn off in Settings. Installing a new version over the old one keeps your settings and your effects.

Where your things are

  • Your effects — Documents\candeo\effects, one .ts file each.
  • Your device definitions — Documents\candeo\devices, one .json file each.
  • Your settings — kept by the app in your profile: what you control, the effect applied, rules, brightness.

Uninstalling Candeo leaves the Documents\candeo folder where it is: your files are yours.
